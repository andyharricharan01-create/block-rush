Block Rush — Privacy Notice

Last updated: October 19, 2026

Block Rush 3.0 is a free browser game. This release does not require an account, collect names, operate chat, request location, integrate ads, or send gameplay information to the game developer.

Game progress, settings and high scores are saved locally in the browser's storage on your device. You can clear this data using your browser's site-data controls or device settings. Exported backup files are stored wherever you choose to save them.

When played on a website, the hosting provider may process standard technical requests and maintain server logs, under the provider's own policies. We do not control those hosting records. This privacy notice applies to the game code distributed in this release and must be reviewed again if analytics, ads, payments or online features are introduced.

For children: the game contains no purchases, targeted advertising, public profiles or communication with strangers. Adult supervision is recommended for younger children.
